# AI Agent Case Management Service

> A Java Spring Boot service for logging and managing issues and recommendations generated by the AI Agent. 

This module integrates with the [AI Agent Common Core](https://github.com/brandontan2003/gcp25_ai_agent_common_core) to provide structured, scalable, and automated case lifecycle tracking.

---

## ✨ Features
- 🧠 Handles **AI-generated issues and recommendations**
- 🔄 Built to integrate with **AI Agent Common Core**
- ☁️ Deployed on **Google Cloud Platform**
- ⚙️ Configurable via Gradle
- 🐳 Docker-compatible deployment support
- 🧾 Structured case tracking and logging service

---

## 📦 Getting Started

### Prerequisites

- Java 11+
- Gradle 6.x+
- Docker
- AI Agent Common Core module - [GitHub Repo](https://github.com/brandontan2003/gcp25_ai_agent_common_core)

> **Important:**
> - Clone and publish the **AI Agent Common Core** module to your local Maven repository:  
    [AI Agent Common Core GitHub Repo](https://github.com/brandontan2003/gcp25_ai_agent_common_core)
>   ```bash
>   git clone https://github.com/brandontan2003/gcp25_ai_agent_common_core.git
>   cd gcp25_ai_agent_common_core
>   ./gradlew clean build publishToMavenLocal
>   ```  

### 🛠️ Installation

```bash
# Clone the repository
git clone https://github.com/brandontan2003/gcp25_ai_agent_case_management_service.git
cd gcp25_ai_agent_case_management_service
./gradlew clean build
docker compose up -d --build
```

# Case Management API Specification

---

## GET /api/case/v1/ticket
**Retrieve a single ticket by its unique ticket ID.**

### Query Parameters

| Name     | Type   | Description           | Required |
|----------|--------|-----------------------|----------|
| ticketId | String | The unique ticket ID. | Yes      |

---

## GET /api/case/v1/tickets
**Retrieve a list of tickets filtered by status, priority, and/or assignee.**

### Query Parameters

| Name     | Type   | Description                                                                    | Required |
|----------|--------|--------------------------------------------------------------------------------|----------|
| status   | String | Filter by ticket status. Allowed values: `OPEN`, `IN_PROGRESS`, `RESOLVED`     | No       |
| priority | String | Filter by ticket priority. Allowed values: `CRITICAL`, `HIGH`, `MEDIUM`, `LOW` | No       |
| assignee | String | Filter tickets assigned to a specific user.                                    | No       |

---

## POST /api/case/v1/ticket
**Create a new ticket with details about the issue.**

### Request Body (JSON)

```json
{
  "title": "Login Page Freezes After Multiple Failed Attempts",
  "description": "Users are reporting that after 3 failed login attempts, the login page becomes unresponsive and requires a refresh. No specific error message is displayed.",
  "assignee": "Brandon",
  "priority": "CRITICAL",
  "status": "OPEN"
}
```

---

## PUT /api/case/v1/ticket
**Update an existing ticket’s details such as assignee, priority, or status.**

### Request Body (JSON)
```json
{
  "ticketId": "1eaeb24d-485f-40c8-b4b7-9ac0fce93674",
  "assignee": "Brandon",
  "priority": "LOW",
  "status": "OPEN"
}
```
